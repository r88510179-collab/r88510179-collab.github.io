# Commercial data boundary

The commercial product is not a clone of the existing personal pool's customer data.

## Allowed reuse

Only generic sports/product mechanics may be reused:

- football week/game concepts
- score/result normalization patterns
- pick validation concepts
- standings/ranking algorithms
- tiebreak concepts
- Survivor elimination logic
- responsive sports-dashboard design patterns

## Prohibited reuse

Do not seed commercial environments with:

- D.C., JC, DJS, Thaddeus, or any other personal-pool participant
- the personal pool's pick history
- personal pool source PDFs
- personal pool standings
- personal pool anonymous entry payloads
- personal branding
- personal commissioner configuration
- personal production database rows

Demo and test fixtures must be synthetic.

## Generic naming

Commercial-facing sports display should support neutral city/team labels configurable by the commissioner. It should not require official league logos, team marks, or league branding.
